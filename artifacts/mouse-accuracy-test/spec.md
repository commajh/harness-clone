# Mouse Accuracy Test — spec.md

## 개요

사용자가 마우스로 지정된 도형을 그리면, 완벽한 도형에 얼마나 근접했는지를 정확도 %와 궤적 위 색상 오버레이로 즉시 보여주는 앱.

---

## 범위

### 포함

- 도형 선택 (원 / 정사각형 / 정삼각형)
- 캔버스 중앙 기준점(+) 표시
- 마우스로 자유 그리기 (mousedown → mousemove → mouseup)
- mouseup 즉시: 이상적 도형 윤곽선 오버레이 + 궤적 색상 피드백 + 정확도 %
- 다시 시도 버튼
- 너무 작게 그렸을 때 경고 메시지

### 제외

- 로그인 / 회원가입 — 재미가 핵심, 계정 마찰 제거
- 점수 저장 / 리더보드 — 핵심 경험 검증 후 추가
- 모바일 터치 — 마우스 정밀도가 긴장감의 원천
- 반응형 레이아웃 — 캔버스는 고정 크기
- 속도 / 떨림 패턴 분석 — MVP 이후

---

## 시나리오

### 1. 페이지 진입 — 초기 상태

- **Given** — 사용자가 앱 URL에 처음 접속한다
- **When** — 페이지가 로드된다
- **Then** — 도형 선택 버튼(원 / 정사각형 / 정삼각형)이 표시되고, 원이 기본 선택된다. 캔버스 중앙에 기준 중심점(+)이 보인다. 정확도 표시는 없다.

성공 기준:
- [ ] 도형 선택 버튼 3개가 보인다
- [ ] "원" 버튼이 선택된 상태로 표시된다
- [ ] 캔버스 중앙에 중심점(+)이 보인다
- [ ] 정확도 숫자가 보이지 않는다

---

### 2. 원 그리기 — 완료 및 결과 표시 (Happy Path)

- **Given** — 원이 선택된 상태, 캔버스에 중심점(+)이 표시되어 있다
- **When** — 사용자가 중심점 주위를 mousedown → mousemove → mouseup으로 그린다 (그린 궤적의 기준 크기 이상)
- **Then** — mouseup 직후, 그린 궤적 위에 색상이 입혀진다. 이상적 원의 윤곽선이 오버레이로 나타난다. 정확도 %가 표시된다. "다시 시도" 버튼이 나타난다.

성공 기준:
- [ ] mouseup 후 그린 궤적 위에 색상 오버레이가 표시된다
- [ ] 궤적 색상이 이상적 원과 가까운 구간은 초록, 오차가 클수록 점진적으로 붉은색이다
- [ ] 이상적 원의 윤곽선이 캔버스에 오버레이로 표시된다
- [ ] 0~100% 범위의 정확도 숫자가 표시된다
- [ ] "다시 시도" 버튼이 표시된다

---

### 3. 정사각형 그리기 — 고정 방향 확인

- **Given** — "정사각형" 도형이 선택된 상태
- **When** — 사용자가 그리기를 완료한다
- **Then** — 이상적 정사각형 오버레이는 변이 수평/수직으로 고정된 방향으로 표시된다

성공 기준:
- [ ] 이상적 정사각형 윤곽선이 수평·수직 변을 가진 형태로 표시된다

---

### 4. 정삼각형 그리기 — 고정 방향 확인

- **Given** — "정삼각형" 도형이 선택된 상태
- **When** — 사용자가 그리기를 완료한다
- **Then** — 이상적 정삼각형 오버레이는 꼭짓점이 위(12시)를 향하는 고정 방향으로 표시된다

성공 기준:
- [ ] 이상적 정삼각형 윤곽선이 꼭짓점이 위를 향한 형태로 표시된다

---

### 5. 다시 시도

- **Given** — 그리기 완료 후 결과가 표시된 상태
- **When** — "다시 시도" 버튼을 클릭한다
- **Then** — 그린 궤적, 오버레이, 정확도 %가 모두 지워진다. 기준 중심점(+)은 그대로 유지된다. 도형 선택은 이전과 동일하게 유지된다. 새로 그리기가 가능하다.

성공 기준:
- [ ] 클릭 후 캔버스에 궤적과 이상적 도형 오버레이가 보이지 않는다
- [ ] 정확도 숫자가 보이지 않는다
- [ ] 중심점(+)이 그대로 표시된다
- [ ] 도형 선택 상태가 유지된다

---

### 6. 도형 변경

- **Given** — 결과가 표시된 상태 또는 그리기 전 상태
- **When** — 다른 도형 버튼을 클릭한다
- **Then** — 캔버스가 초기화된다. 선택한 도형 버튼이 선택 상태가 된다. 기준 중심점(+)은 유지된다.

성공 기준:
- [ ] 클릭 후 기존 궤적과 오버레이가 지워진다
- [ ] 선택한 도형 버튼이 선택 상태로 표시된다
- [ ] 중심점(+)이 그대로 표시된다

---

### 7. 너무 작게 그린 경우

- **Given** — 어떤 도형이든 선택된 상태
- **When** — 사용자가 기준 크기(중심점으로부터 반지름 10px) 미만으로 그리고 mouseup한다
- **Then** — 색상 오버레이와 정확도 %는 나타나지 않는다. 대신 "너무 작습니다. 더 크게 그려주세요" 메시지가 표시된다. 캔버스는 자동으로 초기화된다.

성공 기준:
- [ ] 정확도 숫자가 표시되지 않는다
- [ ] "너무 작습니다. 더 크게 그려주세요" 문구가 표시된다
- [ ] 다음 그리기가 바로 가능하다

## 불변 규칙

**그리기 중 색상 피드백 없음**
mousedown부터 mouseup 직전까지는 궤적이 단색(흰색)으로만 표시된다. 색상 피드백은 mouseup 이후에만 나타난다.

**기준 중심점은 항상 캔버스 중앙에 고정**
도형 변경, 다시 시도, 페이지 새로고침 이후에도 중심점(+)은 캔버스 정중앙에 위치한다.

**이상적 도형 크기는 사용자 그리기에서 자동 결정**
이상적 도형의 크기(반지름 또는 변 길이)는 사용자가 그린 궤적 점들의 중심점까지 평균 거리로 자동 결정된다. 사용자가 따로 크기를 입력하지 않는다.

**오차 비율은 도형 크기 대비 상대값**
색상 결정에 사용되는 오차는 픽셀 절댓값이 아니라 이상적 도형 크기(반지름 또는 변 길이) 대비 비율이다. 크게 그리든 작게 그리든 동일한 기준이 적용된다.
