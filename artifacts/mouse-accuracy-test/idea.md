# Mouse Accuracy Test

## Problem Statement

HMW — 내 손이 어떤 방식으로 틀리는지를, 그린 궤적 위에서 직접 보여줄 수 있을까?

## Recommended Direction

사용자가 Canvas 중앙의 기준점을 보고 도형을 그리면, 즉시 두 가지 피드백을 준다:
정확도 % 숫자 하나, 그리고 그린 궤적 위의 색상 오버레이(완벽한 지점은 초록, 오차 크기에 따라 점진적으로 붉은색).
재도전 버튼으로 반복 시도를 유도한다.

**핵심 UX 결정:**
- 화면에 중심점(+)을 미리 표시하고, 사용자는 그 중심점 기준으로 도형을 그린다 → 피팅 기준점 논쟁 제거
- 오차 색상 스케일은 도형 크기(반지름 또는 변 길이) 대비 상대 비율로 계산 → 크게 그리든 작게 그리든 동일한 기준 적용

**핵심 기술:**
1. 사용자가 그린 점 집합 → 중심점까지의 거리(radius) 평균으로 이상적 반지름 결정
2. 각 점의 실제 거리 vs 이상적 거리 오차 → 도형 크기(반지름) 대비 % 오차로 정규화
3. 오차 비율을 HSL 색상(120° 초록 → 0° 빨강)으로 매핑

## Key Assumptions to Validate

- [ ] 중심점을 미리 보여주면 사용자가 자연스럽게 그 기준으로 그린다 — 첫 5명 반응 확인
- [ ] 궤적 위 초록→붉은색 오버레이가 설명 없이 직관적으로 읽힌다 — 첫 플레이 후 "어디서 틀렸는지 바로 보였냐" 질문
- [ ] 재도전 버튼이 실제로 재시도를 유발한다 (1회에 그치지 않는다)

## MVP Scope

**포함:**
- Canvas 중앙에 기준 중심점(+) 표시
- 자유 그리기 (mousedown → mousemove → mouseup)
- 손 뗀 후 이상적 도형 오버레이 + 궤적 색상 렌더링 (초록 → 붉은색)
- 정확도 % 표시 (100% - 평균 오차비율)
- 도형 선택: 원 / 정사각형 / 정삼각형
- 다시 시도 버튼 (중심점 유지, 캔버스 초기화)

**제외:**
- 로그인, 점수 저장, 리더보드
- 모바일 터치 지원
- 속도·떨림 패턴 분석

## Not Doing (and Why)

- **리더보드** — 저장 인프라가 필요해 MVP가 복잡해진다. 핵심 재미는 자기 자신과의 비교
- **자동 도형 피팅 (최소 제곱법)** — 중심점 고정 방식으로 대체. 더 단순하고 사용자에게 공정하게 느껴진다
- **속도/시간 분석** — 색상 피드백이 직관적인지 먼저 확인
- **모바일** — 마우스의 정밀도가 긴장감의 원천

## Open Questions

- 정삼각형·정사각형의 "이상적 방향(회전각)"은 사용자가 그린 방향에 맞추는가, 아니면 고정하는가?
  → 고정(정삼각형은 꼭짓점 위, 정사각형은 변이 수평)이 더 도전적이고 명확하다
- 오차 색상 변곡점: 0%~5% 오차는 초록, 5%~20%는 노란-주황, 20% 이상은 빨강 — 실제 플레이로 조정 필요
